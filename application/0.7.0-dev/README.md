# DocRelease 0.7.0-dev — комплект для установки

В папке `configuration/` находятся файлы конфигурации DocRelease в формате выгрузки 1С: XML-описания и модули BSL. Это исходники приложения, а не база с документами. Комплект подготовлен для Windows и учебной платформы 1С:Предприятие 8.3.27.1508.

## Как установить

1. Если вы скачали ZIP, распакуйте его целиком средствами Windows.
2. В списке баз 1С добавьте новую файловую базу без конфигурации. Используйте отдельную пустую папку базы.
3. Откройте новую базу в Конфигураторе. При скрытом дереве выберите **Конфигурация → Открыть конфигурацию**.
4. Выберите **Конфигурация → Загрузить конфигурацию из файлов**. Укажите папку `configuration/`, в которой лежит `Configuration.xml`.
5. Выполните **Конфигурация → Проверка конфигурации** с проверкой модулей. При отсутствии ошибок выберите **Конфигурация → Обновить конфигурацию базы данных** и примите предложенные изменения.
6. Создайте пользователей в меню **Администрирование → Пользователи**, назначьте роли. Первым создайте администратора с ролью «Администратор DocRelease».
7. Закройте Конфигуратор и откройте эту базу в режиме **1С:Предприятие**. Войдите под созданным администратором.

Подробные шаги со скриншотами: [руководство по установке](https://docrelease.polakov1245.workers.dev/deployment/).

## Что входит в комплект

- `configuration/` — полный набор файлов конфигурации, включая модули прикладных и служебных проверок. Они оставлены в исходном составе; параметры служебного запуска для обычной установки не нужны.
- `FILES.sha256` — SHA-256 каждого файла конфигурации.

Платформа 1С устанавливается отдельно с официального сайта фирмы «1С». В архиве нет установщика платформы, базы `1Cv8.1CD`, пользовательских данных, учётных записей, паролей и файлов запуска `.cmd` или `.exe`. Пользователей и первые записи вы создаёте после установки. Скриншоты в руководствах показывают отдельно подготовленные учебные данные.

## Просмотр файлов

Откройте [папку конфигурации на GitHub](https://github.com/DmiBear/docrelease/tree/main/application/0.7.0-dev/configuration). Версия папки и ZIP совпадает. Наличие исходников позволяет просмотреть состав и код приложения; контрольная сумма помогает сравнить файлы, но не заменяет проверку содержимого.
