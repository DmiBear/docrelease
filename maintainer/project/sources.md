# Источники, скриншоты и границы проверки

| Источник | Роль и использование |
|---|---|
| `src/Configuration.xml`, XML объектов | Фактическая версия, состав, названия и типы реквизитов |
| `src/CommonModules/*/Ext/Module.bsl` и обработчики объектов | Правила записи, проведения, готовности и защиты |
| Итог приёмки 21.10.2026 | Фактические функциональные результаты; переносимое извлечение в `evidence/` |
| Пользовательские снимки 20.10.2026 | Реальные формы, команды и ранее выполненный основной пример |
| Нативный снимок строки выпуска 20.10.2026 | Просмотр оснований согласования в заполненном выпуске |
| Официальная документация VitePress | Настройка сборки, навигации и локального поиска |

Скриншоты сохранены **без редактирования**. Сопоставление файла, подписи, роли, даты,
версии и SHA-256 находится в `evidence/media-manifest.json`.
Демонстрационные сотрудники и локальные пути на экранах относятся к историческому примеру.
Они не являются настройками новой установки и не должны переноситься как готовые адреса.

Точные правила версии 0.7 имеют приоритет над ранними проектными набросками.
Исторические результаты промежуточных версий не смешиваются с итоговой приёмкой.
Руководства описывают технический порядок; их содержательная приёмка владельцем проекта — отдельное действие.

Технические источники: [VitePress — начало работы](https://vitepress.dev/guide/getting-started),
[локальный поиск](https://vitepress.dev/reference/default-theme-search),
[публикация](https://vitepress.dev/guide/deploy).
Версии зависимостей для этого комплекта фиксирует lock-файл, а не текущая версия сайта VitePress.
