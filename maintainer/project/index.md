# О проекте и архитектуре

DocRelease — учебная система учёта и контроля готовности технической документации к релизу.
Она хранит связи между продуктом, материалами, их редакциями, проверками, планом и выпуском.
Тексты вынесены в Docs-as-Code, а в 1С вручную фиксируются ссылки и идентификаторы.

## Состав решения

```text
Markdown + изображения → проверки → VitePress → сайт / Markdown-комплект
                                             ↓ вручную: ссылка + идентификатор
                          1С: редакция → передача → решение → план → выпуск
```

В прикладной конфигурации 5 справочников, 4 документа, 2 перечисления, 1 регистр сведений,
2 отчёта и общая команда готовности. Прикладные правила находятся в модулях
`ПраваДокументации`, `КонтрольДокументации`, `КонтрольКомплектов`, `ГотовностьКомплектов`
и `КонтрольВыпуска`. Обработчики объектов вызывают проверки перед записью и проведением.

## Что реализовано

Учёт редакций, независимое согласование, возврат с замечанием, обязательный состав,
расчёт всех причин неготовности, снимок выпуска, роли, очередь и история.
Рабочая версия — **0.7.0-dev**. Итоговые автоматизированные TC-01–TC-17 пройдены.

Этот репозиторий добавляет три руководства и воспроизводимую сборку сайта.
Автоматического переноса решения проверяющего из GitHub в 1С нет: содержательное решение
оформляется человеком. Фоновая синхронизация, серверное развёртывание, уведомления,
электронная подпись, нагрузочные испытания и учёт трудозатрат находятся вне текущего комплекта.

Курсовой отчёт отложен по решению автора. Скриншоты и исходники руководств могут быть
использованы позднее, но самостоятельный текст отчёта сейчас не создаётся.
