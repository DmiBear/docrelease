# Состояние и следующие шаги

| Область | Состояние |
|---|---|
| Прикладная версия 0.7.0-dev | Реализована; итоговая автоматизированная приёмка TC-01–TC-17 пройдена |
| Три руководства и справочник | Подготовлены в Markdown для текущей версии |
| Оригинальные скриншоты | Включены с подписями, датами, ролями и контрольными суммами |
| Сайт VitePress | Подготовлены локальный запуск, поиск, светлая и тёмная темы |
| Сборка и контроль | Ссылки, якоря, изображения, версии, снимок исходников и сборка проверяются командами проекта |
| GitHub | Локальный репозиторий подготовлен; удалённая публикация выполняется отдельно |

Ближайший шаг — содержательное рецензирование руководств владельцем проекта и, при необходимости,
повторение описанного маршрута на его отдельной учебной базе. После этого можно фиксировать
редакции готовых файлов и проводить их согласование в 1С.

Позднее отдельно выполняются выбор лицензии, размещение на GitHub/Pages и оформление
экспортных Word/PDF-копий. Курсовой отчёт сейчас отложен. Автоматическая интеграция GitHub
с базой, серверный режим и дополнительные функции не входят в текущую версию.
