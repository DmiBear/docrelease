# Публикация сайта

Исходники документации хранятся в [DmiBear/docrelease](https://github.com/DmiBear/docrelease).
Cloudflare Workers собирает сайт из ветки `main` и публикует его по адресу
[docrelease.polakov1245.workers.dev](https://docrelease.polakov1245.workers.dev/).

## Подготовка изменения

1. Исправьте нужные страницы и выполните `npm.cmd run check`.
2. Откройте собранный сайт и проверьте изменённые инструкции, поиск, ссылки и изображения.
3. Если готовите выпуск трёх руководств, выполните `npm.cmd run release:manifest`.
4. Просмотрите `git status --short` и `git diff`. Убедитесь, что в изменение входят только
   материалы документации и её настройки.

Конфигурация 1С и рабочие базы хранятся отдельно. Каталоги `node_modules/`,
`exports/`, готовый HTML, резервные копии, ключи и журналы не включаются в коммит.

Владелец репозитория создаёт коммит и отправляет подготовленные изменения на GitHub.
Локальная сборка сама по себе не обновляет опубликованный сайт.

Если файлы удалены обычным коммитом, они исчезнут из текущей версии репозитория,
но сохранятся в прежних коммитах. Очистка истории выполняется отдельно.

## Проверка в GitHub Actions

Workflow `Documentation checks` запускает `npm ci --ignore-scripts`, проверки и сборку
на push и pull request. Затем он подготавливает объединённые руководства и сохраняет
результат как артефакт. Проверяются страницы, ссылки, иллюстрации и готовый HTML.

## Публикация в Cloudflare Workers

В панели Cloudflare откройте **Workers & Pages → docrelease**.
Проект подключён к репозиторию GitHub; после отправки в `main` начинается новая сборка.

| Параметр | Значение |
|---|---|
| Репозиторий | `DmiBear/docrelease` |
| Ветка публикации | `main` |
| Корневая папка | `/` |
| Команда сборки | `npm run check` |
| Команда публикации | `npx wrangler deploy` |

В `wrangler.jsonc` указаны имя Worker `docrelease` и каталог готового сайта
`docs/.vitepress/dist`. Сайт размещается в корне домена, поэтому `DOCS_BASE`
оставляют равным `/` или не задают.

На вкладке **Deployments** дождитесь успешного завершения сборки и публикации.
Откройте сайт и проверьте изменённые страницы, переходы между руководствами,
поиск и скриншоты. Изображение должно открываться в полном размере по нажатию.
