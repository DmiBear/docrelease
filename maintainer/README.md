# Сопровождение репозитория

Сайт из каталога `docs/` содержит только руководства по работе с приложением DocRelease.
Эти служебные материалы находятся вне исходников сайта и не входят в его навигацию,
поиск и сборку опубликованных страниц.

- [Сборка и просмотр сайта](site.md).
- [Работа с документацией](documentation/index.md), [редакционные правила](documentation/style.md).
- [Подготовка выпуска](documentation/release.md), [публикация](documentation/publishing.md).

Рабочая база и материалы разработки приложения ведутся отдельно.
В `application/0.7.0-dev/` размещён комплект конфигурации для просмотра на GitHub;
ZIP в `docs/public/downloads/` содержит те же файлы. При замене комплекта
обновите архив, перечень файлов, контрольные суммы и инструкцию установки.
Сведения об изменениях документации — в [CHANGELOG](../CHANGELOG.md).
