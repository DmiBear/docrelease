# Сборка и просмотр документации

Из корня проекта выполните команды по очереди:

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run check
npm.cmd run docs:dev
```

Первая команда устанавливает версии из lock-файла. `check` проверяет страницы,
ссылки и иллюстрации, затем собирает сайт. Последняя команда открывает локальный
сервер разработки; перейдите по адресу, который он напечатает, обычно `http://127.0.0.1:5173`.
Чтобы остановить сервер, нажмите `Ctrl+C` в его окне.

Для просмотра именно готовой сборки:

```powershell
npm.cmd run docs:build
npm.cmd run docs:preview
```

Готовые HTML находятся в `docs/.vitepress/dist`. Не открывайте их двойным щелчком
как отдельные файлы: используйте локальный сервер. Поиск работает в браузере по локальному
индексу и не требует внешнего поискового сервиса.

Для сайта в подпапке задайте `DOCS_BASE`, например `/docrelease/`, **до сборки**.
Для предварительного просмотра соберите с тем же основанием URL:

```powershell
$env:DOCS_BASE = '/docrelease/'
npm.cmd run docs:build
npm.cmd run docs:preview
```

Переменная должна начинаться и заканчиваться `/`. Для возврата к корню удалите её
из текущего сеанса PowerShell и пересоберите сайт.

## GitHub и Cloudflare

В [репозитории DocRelease](https://github.com/DmiBear/docrelease) работает проверка
документации на push и pull request. Сайт публикуется в Cloudflare Workers,
который подключён к ветке `main`.

Отправку изменений выполняет владелец репозитория. После отправки Cloudflare проверяет
и собирает сайт, затем публикует результат. Настройки и порядок проверки описаны
в [инструкции публикации](documentation/publishing.md).

## Оформление и иллюстрации

Сайт использует светлую тему: белая область чтения, тёплая боковая панель и жёлтые акценты.
Таблицы на узком экране прокручиваются внутри страницы. Снимки интерфейса сохранены
в исходном виде; нажмите на изображение, чтобы открыть оригинал.
