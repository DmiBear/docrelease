# DocRelease — подготовка и выпуск документации

DocRelease — учебное приложение на платформе 1С, которое помогает подготовить документацию к выпуску продукта. В нём можно посмотреть, какие документы входят в комплект, кто отвечает за их подготовку и какие редакции уже согласованы.

**[Открыть сайт DocRelease](https://docrelease.polakov1245.workers.dev/)**

Здесь собраны руководство пользователя, руководство администратора и инструкция по установке DocRelease. Документацию можно читать прямо на GitHub или открыть как сайт с навигацией, поиском и скриншотами интерфейса. Сайт подготовлен на VitePress.

## Как работает DocRelease

Подготовка комплекта проходит последовательно:

1. **Автор добавляет документ и его редакцию.** Указывает номер редакции, ссылку на подготовленный текст и передаёт его на проверку.
2. **Проверяющий знакомится с текстом.** Согласует редакцию или возвращает её автору с замечаниями.
3. **Руководитель составляет план комплекта.** Выбирает обязательные документы, назначает ответственных и сроки подготовки.
4. **Перед выпуском проверяется готовность.** Приложение показывает, все ли выбранные редакции согласованы. Если комплект ещё не готов, указывает причины. Когда все условия выполнены, руководитель оформляет выпуск.

Тексты документов хранятся отдельно. DocRelease сохраняет ссылки на них, сведения о редакциях и решения проверяющих. Если текст изменился после передачи на проверку, автор создаёт следующую редакцию. По этим сведениям можно определить, какой именно текст был согласован и вошёл в выпуск.

## Запуск приложения

Для работы нужна установленная учебная платформа 1С. Документация подготовлена для DocRelease **0.7.0-dev** и платформы **8.3.27.1508**.

Комплект DocRelease можно [скачать на странице установки](https://docrelease.polakov1245.workers.dev/deployment/) или [просмотреть в папке application](application/0.7.0-dev/README.md). ZIP и эта папка содержат одинаковые файлы конфигурации. Платформа 1С устанавливается отдельно. Если вы устанавливаете приложение впервые, выполните [инструкцию по созданию базы](docs/deployment/install.md), затем [настройте пользователей и проверьте вход](docs/deployment/first-run.md).

Если DocRelease уже установлен, выберите его базу в списке информационных баз 1С и нажмите **1С:Предприятие**.

## Просмотр документации как сайта

Чтобы открыть сайт на своём компьютере, установите Node.js 22 или новее. В папке DocRelease откройте PowerShell и выполните:

```powershell
npm.cmd ci --ignore-scripts
npm.cmd run docs:dev
```

Первая команда устанавливает необходимые компоненты, вторая запускает сайт. Откройте в браузере адрес, который появится в окне PowerShell. Чтобы остановить сайт, нажмите в этом окне `Ctrl+C`.

Для повторного запуска можно использовать файл `Открыть_документацию.cmd`. Подробнее о просмотре и сборке — в [отдельной инструкции](maintainer/site.md).
