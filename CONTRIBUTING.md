# Работа с документацией

Руководства для пользователей находятся в `docs/`. Размещайте здесь только сведения,
которые помогают установить, настроить или использовать приложение.
Архитектура, планы, результаты испытаний и инструкции по сборке находятся в `maintainer/`.

Для описания операции объясните назначение формы, приведите действия и укажите,
что произойдёт после сохранения. Названия полей и кнопок сверяйте с приложением.
Иллюстрации размещайте рядом с соответствующим действием и ссылайтесь на них в тексте.
Избегайте повторяющихся шаблонных блоков и сведений о внутреннем устройстве, если читателю они не нужны.

Перед передачей изменения выполните `npm run check`, проверьте страницы, поиск и темы в браузере.
Для обновления объединённых руководств используйте `npm run release:manifest`.
Проверки сборки не заменяют проверку фактов и содержательное согласование текста.

Подробности — [сопровождение репозитория](maintainer/README.md).
