# Исходники конфигурации 1С

Снимок прикладной версии **0.7.0-dev** от 21.10.2026. XML и BSL перенесены
без изменений из рабочего проекта. Файлы базы, учётные записи и данные не входят
в этот каталог. Состав и SHA-256 — в `evidence/source-snapshot.json`.

Полный порядок загрузки: руководство по установке, `docs/deployment/install.md`.
Служебные модули `Проверки*` предназначены для испытаний на отдельной базе;
они не заменяют пользовательскую работу и не запускаются при обычном входе.
