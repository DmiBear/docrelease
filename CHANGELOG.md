# Изменения документации

## 1.1.0 — 2026-10-21

- С сайта убраны разделы об архитектуре, приёмке, планах и ведении документации; служебные материалы перенесены в `maintainer/`.
- Переработаны все три руководства и справочник: описание назначения форм, действия пользователя и результат.
- Из навигации и пользовательских страниц убраны сведения о сборке сайта и испытательных запусках.
- Сохранены исходные скриншоты, светлая и тёмная темы.

## 1.0.0 — 2026-10-21

- Созданы три самостоятельных руководства для приложения 0.7.0-dev.
- Добавлены общий справочник, сквозной пример, исходные скриншоты и схема процесса.
- Настроены VitePress, русская навигация, локальный поиск, проверки и ручная публикация Pages.
- Включён неизменённый снимок XML/BSL конфигурации и переносимое извлечение итоговой приёмки.
- Подготовлены создание новой базы, резервирование и восстановление в новый каталог.

- Добавлена жёлтая палитра: светлая тема по умолчанию, штатный переключатель и согласованный тёмный вариант.

Курсовой отчёт, Word/PDF-оформление и автоматическая интеграция GitHub с 1С отложены.
