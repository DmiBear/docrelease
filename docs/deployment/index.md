# Руководство по установке

Для работы DocRelease нужна файловая информационная база на учебной платформе 1С.
Это руководство поможет подготовить её, настроить пользователей и выполнить первый вход.

1. Ознакомьтесь с [требованиями к установке](requirements.md).
2. [Создайте базу и загрузите конфигурацию](install.md).
3. Выполните [первоначальную настройку](first-run.md).

Если база уже используется, повторная первоначальная установка не требуется.
Порядок перехода на новую версию описан в разделе
[«Обновление и обслуживание»](../admin/maintenance.md).
