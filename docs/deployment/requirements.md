# Подготовка к установке

DocRelease работает в файловой базе на локальном диске. Описанный порядок рассчитан
на Windows и учебную платформу **1С:Предприятие 8.3.27.1508**.

## Что понадобится

| Компонент | Назначение |
|---|---|
| Установленная учебная платформа 1С | Запуск приложения и Конфигуратора |
| Файлы конфигурации DocRelease | Загрузка приложения в новую базу; находятся в каталоге `src/` |
| Отдельная папка базы | Хранение данных приложения |
| Право записи в эту папку | Создание и дальнейшее сохранение данных |

Установщик платформы не входит в комплект DocRelease. Установите платформу до создания базы.
Доступность других версий 1С нужно проверять отдельно.

## Выбор папки

Для новой базы выберите отдельную папку. Если вы используете вспомогательные файлы
из комплекта, по умолчанию база создаётся в `.local/infobase` рядом с ними.
Существующие рабочие базы при первоначальной установке не изменяются.

Учебная платформа поддерживает один сеанс. Перед установкой закройте её открытые окна,
включая Конфигуратор и список баз.

Для обычной работы с DocRelease достаточно установленной 1С. Node.js нужен только
для дополнительного способа установки с помощью команды, описанного в следующем разделе.
