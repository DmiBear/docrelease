# Подготовка к установке

DocRelease работает в файловой базе на локальном диске. Описанный порядок рассчитан
на Windows и учебную платформу **1С:Предприятие 8.3.27.1508**.

## Что понадобится

| Компонент | Назначение |
|---|---|
| Установленная учебная платформа 1С | Запуск приложения и Конфигуратора |
| Отдельно полученные файлы конфигурации DocRelease | Загрузка приложения в новую базу через Конфигуратор |
| Отдельная папка базы | Хранение данных приложения |
| Право записи в эту папку | Создание и дальнейшее сохранение данных |

Перед созданием базы установите платформу и подготовьте файлы конфигурации DocRelease.
Конфигурация приложения и установщик платформы предоставляются отдельно от этого сайта
и репозитория документации. Доступность других версий 1С нужно проверять отдельно.

## Выбор папки

Для новой базы выберите отдельную пустую папку на локальном диске.
Укажите её при добавлении информационной базы в список 1С.
Папку существующей рабочей базы для первоначальной установки использовать не нужно.

Учебная платформа поддерживает один сеанс. Перед установкой закройте её открытые окна,
включая Конфигуратор и список баз.
