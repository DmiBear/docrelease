# Установка новой базы

Создайте отдельную информационную базу и загрузите в неё файлы DocRelease.
Если вы собираетесь обновить уже работающую базу, используйте
[порядок обновления](../admin/maintenance.md).

## Создание и загрузка базы

1. Откройте список информационных баз учебной 1С и нажмите **Добавить**.
2. Создайте новую файловую информационную базу без конфигурации.
   Укажите её имя и отдельную папку на локальном диске.
3. Откройте созданную базу в **Конфигураторе**.
4. В меню **Конфигурация** выберите **Загрузить конфигурацию из файлов**.
   Укажите каталог `src` из комплекта DocRelease.
5. Выполните **Конфигурация → Проверка конфигурации**, включив проверку модулей.
6. При отсутствии ошибок выполните **Конфигурация → Обновить конфигурацию базы данных**.

После загрузки в дереве Конфигуратора отобразится DocRelease (рисунок 15).
В свойствах корня проверьте имя и версию конфигурации — **0.7.0-dev**.

[![Рисунок 15 — Конфигурация DocRelease в Конфигураторе.](/images/ui-15-designer.png)](/images/ui-15-designer.png)

Установка завершена после обновления конфигурации базы данных.
Далее создайте пользователей и выполните [первый запуск](first-run.md).

<details>
<summary>Создание базы с помощью команды</summary>

Этот вариант подойдёт, если установлен Node.js 22 или новее.
В PowerShell, открытом в папке DocRelease, выполните:

```powershell
node .\tools\database.mjs create
```

Команда создаст новую базу `.local/infobase`, загрузит конфигурацию, проверит модули
и обновит базу данных. Каталог должен быть пустым, а путь — без пробелов.
Если в нём уже есть база, выполнение остановится без замены данных.

По умолчанию используется учебная платформа 8.3.27.1508 из стандартного каталога установки.
Если путь отличается, укажите его отдельно:

```powershell
node .\tools\database.mjs create --platform "путь-к-1cv8t.exe"
```

Сообщения сохраняются в `.local/setup/`. Если произошла ошибка, ознакомьтесь с журналом
и устраните причину перед следующей попыткой.

</details>
