# Создание базы и загрузка DocRelease

К этому шагу платформа 1С должна быть установлена, а ZIP — полностью распакован.
Если это ещё не сделано, вернитесь к [подготовке](requirements.md).
Устанавливайте DocRelease в новую базу: для существующей базы с данными есть
[отдельный порядок обновления](../admin/maintenance.md).

## Создать пустую базу

1. Запустите **1С:Предприятие**. В окне со списком информационных баз нажмите **Добавить**.
2. Выберите **Создание новой информационной базы** и нажмите **Далее**.
3. Выберите **Создание информационной базы без конфигурации** и снова нажмите **Далее**.
4. Введите имя, например `DocRelease`. Выберите размещение **На данном компьютере или на компьютере в локальной сети**.
5. Укажите подготовленную отдельную папку базы на локальном диске. Остальные параметры оставьте предложенными мастером.
6. Завершите мастер кнопкой **Готово**.

В списке появится новая база с выбранным именем. Пока она пуста и ещё не содержит DocRelease.
Порядок создания базы без конфигурации также описан в
[руководстве платформы 1С](https://its.1c.ru/db/content/edtdoc/src/topics/t000454.html).

## Загрузить файлы приложения

1. Выберите новую базу в списке и нажмите **Конфигуратор**.
2. Если дерево конфигурации слева скрыто, выберите **Конфигурация → Открыть конфигурацию**.
3. Выберите **Конфигурация → Загрузить конфигурацию из файлов**.
4. Выберите загрузку из **XML-файлов** и укажите папку **configuration** из распакованного комплекта. В ней должен находиться `Configuration.xml`.
5. Нажмите **Загрузить** и дождитесь окончания операции.

Слева появится дерево с корнем **DocRelease**, справочниками, документами и отчётами
(рисунок 1). Это показывает, что файлы загружены. Следующим действием нужно
обновить конфигурацию базы данных.

## Применить конфигурацию к базе

1. Выполните **Конфигурация → Проверка конфигурации**, включите проверку модулей и запустите её.
2. Если проверка не выявила ошибок, выберите **Конфигурация → Обновить конфигурацию базы данных**.
3. Если появится окно с перечнем изменений структуры, примите предложенные изменения.
4. Дождитесь завершения обновления. После этого переходите к [настройке пользователей](first-run.md).

Загрузка файлов меняет описание приложения в Конфигураторе. Обновление базы данных
применяет это описание к самой базе. Для первого запуска нужны оба действия.

## Если что-то не получилось

| Что произошло | Что проверить |
|---|---|
| Нет `Configuration.xml` | Открыта не та папка или ZIP не распакован. Нужна вложенная папка `configuration` |
| Команда загрузки недоступна | Вы открыли базу кнопкой **Конфигуратор** и открыли конфигурацию через одноимённое меню |
| При проверке появились ошибки | Сохраните текст сообщения. Проверьте версию платформы и полноту распакованного комплекта; не переходите к обновлению с неустранённой ошибкой |
| При запуске не видно разделов DocRelease | Проверьте, что обновлена конфигурация базы данных и пользователю назначена роль |

Другие причины ошибок разобраны в разделе [«Помощь при неполадках»](../admin/diagnostics.md).
