# Установка новой базы

Подготовьте отдельно полученные файлы конфигурации DocRelease: они не входят
в репозиторий документации. Создайте отдельную информационную базу и загрузите в неё эти файлы.
Если вы собираетесь обновить уже работающую базу, используйте
[порядок обновления](../admin/maintenance.md).

## Создание и загрузка базы

1. Откройте список информационных баз учебной 1С и нажмите **Добавить**.
2. Создайте новую файловую информационную базу без конфигурации.
   Укажите её имя и отдельную папку на локальном диске.
3. Откройте созданную базу в **Конфигураторе**.
4. В меню **Конфигурация** выберите **Загрузить конфигурацию из файлов**.
   Укажите папку с полученными файлами конфигурации. В ней должен находиться файл `Configuration.xml`.
5. Выполните **Конфигурация → Проверка конфигурации**, включив проверку модулей.
6. При отсутствии ошибок выполните **Конфигурация → Обновить конфигурацию базы данных**.

После загрузки в дереве Конфигуратора отобразится DocRelease (рисунок 15).
В свойствах корня проверьте имя и версию конфигурации — **0.7.0-dev**.
