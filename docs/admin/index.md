# Руководство администратора

Администратор готовит базу к работе, создаёт пользователей и назначает им роли.
Он также отвечает за резервные копии, обновление приложения и восстановление данных при сбое.

| Задача | Раздел руководства |
|---|---|
| Добавить пользователя и назначить ему роль | [Пользователи и сотрудники](users.md) |
| Сохранить базу и восстановить её из копии | [Резервное копирование](backup.md) |
| Загрузить обновление приложения | [Обновление и обслуживание](maintenance.md) |
| Найти причину ошибки | [Помощь при неполадках](diagnostics.md) |

Если DocRelease ещё не установлен, начните с [руководства по установке](../deployment/index.md).
Порядок работы с документами описан в [руководстве пользователя](../user/index.md).

## Пользователь базы и сотрудник

Пользователь базы выбирается при входе в 1С. Его роль определяет доступные действия.
Сотрудник — участник работы с документами: автор, проверяющий, ответственный или куратор.

Для автора и проверяющего нужно связать учётную запись с карточкой сотрудника.
По этой связи приложение определяет, кто создаёт редакцию или принимает решение.
Одного совпадения имён недостаточно.

## База и тексты документов

База хранит карточки, передачи, решения и состав выпусков. Сам текст документа находится
по внешней ссылке. При резервировании сохраняйте и базу, и файлы документов: одной копии
базы недостаточно, чтобы восстановить текст, удалённый из внешнего хранилища.

Рисунки нумеруются последовательно в пределах этого руководства.
Нажмите на скриншот, чтобы открыть его в исходном размере.
