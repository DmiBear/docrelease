# Отчёты

Отчёты помогают найти тексты, ожидающие проверки, и посмотреть решения по выбранной редакции.
Они доступны в разделе **Документация → Отчёты**.

## Документы на проверке

Отчёт показывает редакции, по которым ещё не завершена проверка.

1. Откройте **Отчёты → Документы на проверке**.
2. В настройках при необходимости выберите **Продукт** и **Проверяющего**.
3. Нажмите **Сформировать**.

В результате будут показаны документы, номера редакций и назначенные проверяющие.
Если заданы оба условия, останутся передачи выбранного продукта этому сотруднику.
При пустых условиях отображается вся очередь.

После согласования или возврата редакция уходит из очереди. Если строк нет, проверьте
условия отбора: возможно, выбранных заданий уже нет на проверке.

## История редакции

В истории можно посмотреть, когда редакцию передавали на проверку, кто принимал решение
и какие замечания были записаны.

1. Откройте **Отчёты → История редакции**.
2. В настройках выберите **Редакцию**.
3. Нажмите **Сформировать**.

Для каждой редакции ведётся своя история. Выбирайте нужный номер, даже если у документа
уже есть более новая версия текста. В отчёт входят действующие проведённые передачи и решения;
отменённые проведения в нём не показываются.

## Готовность комплекта

Готовность открывается из плана кнопкой **Проверить готовность**.
Она показывает состояние всего комплекта и причины, мешающие выпуску.
Порядок работы приведён в разделе [«Проверка готовности»](readiness.md).

Сотрудники могут просматривать общие данные и отчёты. Роль ограничивает изменение
записей, но не скрывает чужие документы из списков.
