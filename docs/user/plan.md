# План комплекта

В плане руководитель выпуска определяет, какие документы должны войти в релиз.
Для каждого документа указываются редакция, ответственный и срок подготовки.

## Создание плана

1. Откройте **Документация → План комплекта** и нажмите **Создать**.
2. Заполните основные сведения о релизе.

| Поле | Назначение |
|---|---|
| **Дата** | Дата составления плана |
| **Продукт** | Продукт, для которого готовится документация |
| **Номер релиза** | Обозначение выпуска продукта, например `1.2` |
| **Куратор** | Сотрудник, отвечающий за подготовку комплекта |

Карточка нового плана показана на рисунке 10.

[![Рисунок 10 — Создание плана комплекта.](/images/ui-10-plan.png)](/images/ui-10-plan.png)

*Рисунок 10 — Создание плана комплекта.*

3. Нажмите **Добавить** над таблицей документов.
4. Выберите **Документ продукта** и его **Редакцию**, назначьте **Ответственного** и **Срок подготовки**.
5. Добавьте остальные обязательные документы.
6. Нажмите **Записать и закрыть**.

План появится в списке (рисунок 11).

[![Рисунок 11 — Список планов комплекта.](/images/ui-11-plans.png)](/images/ui-11-plans.png)

*Рисунок 11 — Список планов комплекта.*

## Заполнение состава

Включайте каждый документ в план один раз. Документ должен относиться к продукту из шапки
плана, а выбранная редакция — к этому документу. Повторяющийся документ или чужую редакцию
приложение не позволит сохранить.

Если текст ещё готовится, редакцию можно выбрать позже. Однако для записи плана
нужны хотя бы одна строка, ответственные и сроки. Для выпуска потребуется согласованная редакция
в каждой строке.

Номер релиза продукта и номера редакций документов могут различаться.
После заполнения сохраните план и выполните [проверку готовности](readiness.md).
