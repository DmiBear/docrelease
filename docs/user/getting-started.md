# Начало работы

Для входа в DocRelease нужен пользователь базы, созданный администратором. Если приложение
ещё не установлено, воспользуйтесь [руководством по установке](../deployment/index.md).

## Вход в приложение

1. Откройте папку DocRelease и запустите файл `Открыть_DocRelease.cmd` двойным щелчком мыши.
2. В окне входа выберите своего пользователя и нажмите **Войти**.
3. После открытия главного окна проверьте имя пользователя в правой части верхней панели.

Главное окно приложения показано на рисунке 1. Состав доступных команд зависит от назначенной роли.

## Разделы приложения

Основные действия распределены между двумя разделами.

| Раздел | Что можно открыть |
|---|---|
| **НСИ** | Продукты, виды документации, документы продуктов, редакции документов и сотрудников |
| **Документация** | Передачи на проверку, результаты проверки, планы, выпуски и отчёты |

Для перехода выберите раздел, затем нужную команду. Откроется список записей.
Чтобы добавить запись, нажмите **Создать**. Для просмотра существующей карточки откройте её из списка.

Панель разделов может находиться сверху или слева. Её расположение сохраняется отдельно
для каждого пользователя и не влияет на доступные действия.

## Сохранение и проведение

Кнопка **Записать** сохраняет введённые данные. Звёздочка возле заголовка формы означает,
что в ней есть несохранённые изменения.

Для передачи текста, принятия решения и выпуска комплекта используется **Провести**.
Например, сохранённая передача остаётся черновиком, а после проведения редакция переходит
в состояние «На проверке». Кнопка **Провести и закрыть** выполняет это действие и закрывает карточку.

План комплекта достаточно сохранить кнопкой **Записать и закрыть**.

## Завершение работы

Сохраните открытые карточки и закройте приложение. Если нужно войти под другим пользователем,
снова запустите DocRelease и выберите его в окне входа. В учебной версии 1С пользователи
работают последовательно, в одном сеансе.
