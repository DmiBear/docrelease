# Выпуск комплекта

Выпуск фиксирует, какие редакции документов подготовлены для релиза и кем они согласованы.
Его оформляет руководитель после [проверки готовности](readiness.md).

## Оформление выпуска

1. Откройте **Документация → Выпуск комплекта** и нажмите **Создать**.
2. В поле **План комплекта** выберите сохранённый план из списка.
3. Укажите дату и время выпуска. Они не должны быть раньше согласования документов комплекта.
4. Нажмите **Провести** или **Провести и закрыть**.

При проведении приложение повторно проверит готовность и заполнит данные из плана.
В карточке появятся продукт, номер релиза, куратор и список документов (рисунок 13).

В таблице сохраняются редакции, ответственные, сроки, ссылки на проверенные тексты
и сведения о согласовании. Часть столбцов находится справа: для просмотра переместите
горизонтальную полосу прокрутки (рисунок 14).

[![Рисунок 14 — Сведения о согласовании документов в выпуске.](/images/ui-14-snapshot.jpg)](/images/ui-14-snapshot.jpg)

Проверьте число строк и выбранные редакции. Сохранённый, но не проведённый черновик
ещё не подтверждает выпуск. Его состав заполняется заново при проведении.

## Работа после выпуска

Состав проведённого выпуска сохраняется. Если автор создаст следующую редакцию,
в уже оформленном выпуске останется прежний текст.

Использованные в выпуске план, редакции и решения защищены от изменения.
Для следующего релиза создайте новый план и выберите нужные редакции.
Если вы только просматриваете проведённый выпуск, закройте карточку без повторной записи.

## Исправление ошибочного выпуска

Если выпуск оформлен ошибочно, сначала согласуйте исправление с ответственным за релиз.
В списке **Выпуск комплекта** выберите документ и выполните отмену проведения через меню **Ещё**.
Убедитесь, что проведение снято, затем внесите необходимые исправления и повторите проверку готовности.

После отмены прежний состав ещё виден в карточке. При сохранении черновика он очищается,
а при новом проведении заполняется по сохранённому плану. Если приложение сообщает
о зависимых документах, обратитесь к администратору.
