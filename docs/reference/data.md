# Справочники и документы

В справочниках хранятся основные сведения о продуктах, текстах и сотрудниках.
Рабочие действия — передача, проверка и выпуск — оформляются документами.

## Справочники раздела «НСИ»

| Справочник | Для чего используется |
|---|---|
| **Продукты** | Продукты, для которых готовится документация |
| **Виды документации** | Виды материалов, например руководство или инструкция |
| **Документы продуктов** | Карточки документов с указанием продукта и вида |
| **Редакции документов** | Версии текста с номером, автором, ссылкой и идентификатором |
| **Сотрудники** | Участники подготовки документации и их связи с пользователями базы |

У одного документа может быть несколько редакций. Они различаются номером и проверяются отдельно.
Номер редакции может содержать до 40 символов, ссылка на текст — до 1000,
идентификатор содержимого — до 128.

## Документы раздела «Документация»

| Документ | Что в нём указывается |
|---|---|
| **Передача на проверку** | Редакция, назначенный проверяющий, дата и время передачи |
| **Результат проверки** | Передача, проверяющий, решение и замечание |
| **План комплекта** | Продукт, релиз, куратор и обязательные документы с редакциями, ответственными и сроками |
| **Выпуск комплекта** | Выбранный план и состав документов с подтверждением согласования |

Ссылка и идентификатор текста в передаче заполняются при проведении из выбранной редакции.
Состав выпуска и сведения о согласовании также заполняются автоматически — по сохранённому плану.

Срок подготовки в плане относится к подготовке документа. Дата передачи показывает,
когда текст поступил проверяющему; отдельный срок проверки в приложении не задаётся.
