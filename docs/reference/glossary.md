# Термины

| Термин | Значение |
|---|---|
| **Продукт** | Программа или другой продукт, для которого готовится документация |
| **Документ продукта** | Карточка материала, например руководства пользователя |
| **Редакция** | Отдельная версия текста с номером, автором и ссылкой |
| **Идентификатор содержимого** | Значение, позволяющее отличить конкретную версию текста от другой |
| **Контрольная сумма** | Набор букв и цифр, рассчитанный по содержимому файла; при изменении файла меняется |
| **Передача на проверку** | Документ, которым автор направляет редакцию назначенному проверяющему |
| **Результат проверки** | Решение о согласовании текста или его возврате с замечанием |
| **Релиз** | Выпуск продукта, для которого нужен определённый комплект документов |
| **План комплекта** | Перечень обязательных документов релиза с редакциями, ответственными и сроками |
| **Готовность комплекта** | Результат проверки, все ли обязательные документы согласованы и заполнены |
| **Выпуск комплекта** | Документ, фиксирующий состав готовой документации и сведения о согласовании |
| **Проведение** | Действие, после которого передача, решение или выпуск вступают в силу |

В результате проверки выбирается решение **«Согласовано»**.
После его проведения состояние редакции называется **«Согласована»**.
